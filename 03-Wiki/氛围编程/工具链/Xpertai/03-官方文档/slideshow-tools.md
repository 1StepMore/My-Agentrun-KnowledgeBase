# Slide Tool

<Tip>
  **PRO**

  This feature is available in the **Pro version**.
</Tip>

XpertAI's agent system comes with a powerful **slide toolset**, providing AI with programmable virtual workspace slide operations. This enables agents to **create, edit, delete, and list** workspace slides during execution.
