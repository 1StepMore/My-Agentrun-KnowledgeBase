# Hermes Agent 使用指南

## 概述

> **Hermes Agent** 是 Nous Research 开源的自主 AI Agent 框架，Slogan：**"The agent that grows with you（随你共同成长的智能体）"**
> 
> 核心杀手锏：**[[自我学习]] + [[记忆沉淀]]** → 越用越懂你

## 核心定位

| 属性 | 说明 |
|------|------|
| 开发方 | [[Nous Research]] |
| 类型 | 自主 AI Agent 框架 |
| 核心理念 | 自我学习与记忆沉淀 |
| 使用价值 | 随使用频次呈[[复利原则\|指数级增长]] |

## 核心路径

```bash
~/.hermes/
├── MEMORY.md      # [[长期记忆]]（手动维护）
├── USER.md        # [[用户画像]]
└── skills/        # [[技能库]]（备份到 GitHub）
```

## 总结

Hermes Agent 的核心价值在于**持续使用**带来的[[复利效应]]。与传统无状态大模型不同，它通过 [[MEMORY.md]] 和 [[Skill]] 实现[[记忆沉淀]]。使用关键是：
1. **高频使用** → 积累精准记忆
2. **结果导向** → 给 Agent [[规划权]]
3. **透明维护** → 直接编辑记忆文件
4. **精简为王** → 保持高信噪比
5. **人机协作** → 关键决策点人工确认

# Hermes 5大核心心法

> 来源：[[Hermes Agent 使用指南]]

## 一、复利原则（Accumulation）

> 不要把它当成一次性问答工具。Hermes 的核心价值在于**[[高频使用]]**。

- 使用次数越多，[[Skill]] 和 [[Memory]] 越精准
- 价值随时间呈**[[复利效应|指数级增长]]**

**核心逻辑**：[[长期主义]]

---

## 二、结果导向原则（Outcome-First）

> 关注"要什么"，而非"怎么做"。

- 不要[[微操]] Agent
- 直接赋予 Agent **[[规划权]]（Planning）**

**反面案例**：给出详细步骤清单  
**正确做法**：只说目标，让 Agent 自己规划路径

---

## 三、透明化原则（Transparency）

> Hermes 是一个"[[白盒]]"Agent。

- 可随时查看 `~/.hermes/` 目录
- **直接编辑** [[记忆文件]] 和 [[技能文件]]

**核心优势**：完全可控，可审计，可干预

---

## 四、精简记忆原则（Minimalist Memory）

> **记忆不是越多越好，而是越准越好。**

- 上下文越长，越容易产生[[幻觉]]
- [[Token]] 成本越高
- 定期[[修剪]]冗余信息，保持"[[高信噪比]]"

**操作建议**：
- 定期打开 [[MEMORY.md]]
- 删除过时需求
- 写入核心偏好

---

## 五、人机协作原则（Human-in-the-loop）

> 在关键**[[决策点]]**，务必要求人工确认。

**必须介入的场景**：
- 删除服务器文件
- 发送敏感邮件
- 提交 [[PR]]（Pull Request）

**原则**：AI 负责执行，人负责把关

---

## 心法总结

| 原则 | 关键词 | 核心行动 |
|------|--------|----------|
| 复利原则 | [[高频使用]] | 坚持每日使用 |
| 结果导向 | [[规划权]] | 只说目标 |
| 透明化 | [[白盒]] | 直接编辑文件 |
| 精简记忆 | [[高信噪比]] | 定期修剪 |
| 人机协作 | [[决策点]] | 关键操作确认 |

## 👑 核心配置篇

| # | 技巧 | 关键操作 |
