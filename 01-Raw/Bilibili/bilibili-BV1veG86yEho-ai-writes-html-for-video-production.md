## 核心观点

AI 写 HTML → 动画 → 视频，零基础也能做。

**工作流**：
1. 用自然语言描述想要的视频
2. AI 生成 HTML/CSS/JS 动画
3. 通过工具渲染/导出为视频文件

## 生态判断

HTML 转视频正在形成完整的工具链：
1. **生成层**：AI agent（Claude Code / Codex / Cursor）写 HTML
2. **渲染层**：Remotion / hyperframes / svganimate / 浏览器录制
3. **输出层**：mp4 / webm 视频文件

这个路线比传统剪辑软件更轻量、更可编程、更适合 AI 生产。
