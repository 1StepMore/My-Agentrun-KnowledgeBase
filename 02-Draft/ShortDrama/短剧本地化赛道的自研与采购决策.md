# 短剧本地化赛道的自研与采购决策

## 核心决策框架：按子类成熟度分层，而非一刀切

短剧本地化涉及十余个技术子类，从字幕翻译到文化适配，AI 成熟度差异悬殊。有效的决策不是“自研还是采购”的二元选择，而是**按子类的 AI 成熟度、成本结构、战略价值三个维度分层决策**。

**三个决策判据：**

| 判据 | 自研（🔵） | 采购（🟢） | 人工主导（🔴/🟠） |
|------|-----------|-----------|------------------|
| API 成本 | 极低（单集 <0.01 元） | 中等（按量计费） | 高（人工工时） |
| AI 成熟度 | >90% 准确率，可标准化 | 技术门槛高，自研 ROI 低 | AI 理解力不足，错误成本高 |
| 战略价值 | 流程控制、数据沉淀、边际成本优势 | 快速上线，避免重复造轮子 | 不可替代的创意/合规判断 |

**典型分层结果：**

- **自研**：字幕翻译、元数据本地化、文化适配清单——API 成本趋近于零，且能积累翻译记忆库与术语库
- **采购**：硬字幕擦除、TTS 配音、口型同步——技术门槛高（SOTA 模型需百万级投入），或已有成熟低价 API
- **人工主导**：合规终审、本地化剪辑、文化改编——AI 仅能辅助提效，错误成本高

---

## 成本结构的两个关键认知

### 1. 翻译成本趋近于零，不是决策重点

单集短剧（约 90 秒，300 字对白）的字幕翻译 API 成本已降至 **0.001–0.04 元**，即使日跑万集，月成本不过数百元。翻译环节占全流程成本的比例通常低于 10%。

**推论**：选择翻译模型时，质量稳定性与风格一致性比单价更重要。模型版本迭代可能导致翻译风格突变，需建立质量回归机制。

### 2. 真正的成本大头在“非翻译环节”

以全流程 API 成本拆解为例（100 集 × 9 语种）：

| 工序 | 成本占比 | 说明 |
|------|---------|------|
| 硬字幕擦除 | ~18% | 共享成本，按源片分钟计费 |
| AI 配音（音色 ID） | ~28% | 单语种独占，按成品分钟计费 |
| 音色克隆 | ~37% | 一次性投入，按音色数计费 |
| 其余（ASR/翻译/OCR/压制/审核） | ~17% | 多为共享或低成本环节 |

**关键洞察**：擦除与配音合计占全流程成本的一半以上。**自研的真正价值在于降低这两个环节的边际成本，而非翻译环节。**

---

## 硬字幕擦除：自研 vs 采购的典型算账

这是全流程中开源与商业方案成本差距最大的环节，也是决策模型的最佳示例。

| 方案 | 单价 | 月成本（1000 集 × 150 分钟源片） |
|------|------|--------------------------------|
| 商业 API（按量） | 3 元/分钟 | ~450,000 元 |
| 自部署开源模型（GPU） | 1 张 3090 ≈ 3000 元/月电费 | ~5,000 元 |

**量化门槛**：当月产量超过约 **200 集**（或源片分钟数超过约 3 万分钟/月），自部署 GPU 的固定成本即可摊薄低于商业 API 的按量费用。

**推荐策略**：
- **MVP 阶段**：直接采购商业 API，1–2 天集成，最快跑通业务验证
- **规模化阶段**：常规片源自部署开源模型（如光流引导的视频修复方案），复杂场景（低清晰度、动态背景）保留商业 API 兜底

**注意**：商业 API 的定价针对偶发用户，大批量使用必须重新核算。开源方案需自行处理帧间闪烁、部署运维等工程问题。

## 配音环节：许可证与质量的分层选择

配音是“配音剧”路线的核心，也是成本最高的单点环节。决策需同时考虑**许可证合规性**与**质量分层**。

### 开源 TTS 的许可证陷阱

| 方案 | 许可证 | 商用限制 |
|------|--------|---------|
| 方案 A | Apache 2.0 | 无限制，跨语言克隆能力强 |
| 方案 B | CC BY-NC-SA 4.0 | **禁止商用**，中文自然度最高 |
| 方案 C | Apache 2.0 | 无限制，但社区成熟度较低 |

**判据**：对外提供服务必须核查许可证。非商用/研究场景可选用中文质量更高的受限方案，商用场景必须选 Apache 2.0 或采购商业 API。

### 质量分层与人工干预比例

| 档位 | AI 能力 | 人工干预 | 适用场景 |
|------|---------|---------|---------|
| 标准 TTS（音色 ID） | 无明显机械感 | 10–20% 抽检 | 长尾集、广告版 |
| 高情感克隆 | 情感表达 80% 到位 | 30–50% 精修 | 主线剧、付费档 |
| 顶尖精品 | 仍需人工 | 60–80% 人工 | S 级项目 |

**ROI 判据**：配音剧比字幕剧用户规模高约 144%，但单集成本高 3–5 倍。约 **11 万次播放**即可覆盖成本差额——低于此播放预期的内容建议走字幕剧路线。

## 合规审查：AI 初筛 + 人工终审的必然组合

合规审查是“错误成本最高”的环节，也是 AI 成熟度评估中最需要保守的领域。

| 审查类型 | 开源 AI 能力 | 商业 API 能力 | 人工必要性 |
|---------|-------------|-------------|-----------|
| 暴力/色情 | 基础多分类 | 强，多标签 | 低（AI 可覆盖） |
| 文化敏感/宗教/政治 | 不支持 | 部分支持 | **必须人工** |

**推荐架构**：
1. **开源模型初筛**：过滤明显违规内容（暴力/色情），成本为零
2. **商业 API 辅助**：对高风险内容做二次标记（约 0.08 元/分钟）
3. **人工终审**：对 AI 标记的违规帧 + 时间戳进行确认/驳回

**关键原则**：AI 在合规环节只能做“提效工具”，不能做“决策主体”。文化禁忌、宗教敏感、政治红线必须人工判断。

## 报价策略：三层定价模型

基于成本结构，建议设计三层报价体系，对应不同客户需求：

| 层级 | 定价基准 | 服务内容 | 目标客户 |
|------|---------|---------|---------|
| L1 经济型 | 平台价的 1.5–2 倍 | AI 全自动 + 机器抽检（5%） | 跑量型客户 |
| L2 标准型（主力） | 人工价的 30–40% | AI + 人工精审（30% 抽检）+ 翻译记忆库 | 品质客户 |
| L3 精品型 | 人工价的 60–80% | AI + 全流程人工精审 + 文化适配清单 + 合规报告 | 品牌客户 |

**定价依据**：
- 纯人工市场价（中→英）：100–300 元/千字
- AI 平台价：0.2–1 元/分钟（基础翻译）
- 建议区间：人工价的 30–40%，体现“AI 效率 + 人工精校”的增值

**差异化窗口**：小语种（粤语、葡语等）平台覆盖弱，可定高价（人工价的 40–60%）。主流语种（英/美）竞争激烈，靠质量与交付速度差异化。

## 实施路线：四阶段演进

| 阶段 | 核心动作 | 投入 | 周期 |
|------|---------|------|------|
| **Phase 1: MVP** | 调通 LLM 翻译管线（1–2 个语种），采购擦除/配音 API | 1–2 人月 | 2–3 周 |
| **Phase 2: 集成** | 补齐配音、审核链路，建立基础 HITL 界面 | 0.5–1 人月 | 1–2 周 |
| **Phase 3: 差异化** | 建设文化适配清单系统、翻译记忆库、术语库 | 1–2 人月 | 2–4 周 |
| **Phase 4: 规模化** | 自部署擦除模型降本，流程编排 + 质量评估体系 | 1–2 人月 | 2–4 周 |

**关键原则**：MVP 阶段不要自研任何技术门槛高的环节（擦除、配音），先跑通业务验证。降本动作放在规模化阶段。

---

## 风险清单

1. **模型价格持续下降**：自研边际成本越来越低，但需关注质量稳定性（版本迭代可能改变翻译风格）
2. **小语种数据稀缺**：粤语/葡语训练数据远少于英语，模型表现可能不如预期，需准备双语语料做 few-shot
3. **客户期望管理**：AI 辅助 ≠ 零人工，需在合同中明确定义人工审核环节的价值
4. **合规动态变化**：各市场要求持续变化，需建立常态化监控机制
5. **许可证合规**：开源组件的商用限制（如 CC BY-NC-SA）可能成为法律风险，选型时需优先核查
