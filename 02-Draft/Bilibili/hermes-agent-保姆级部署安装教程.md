# Hermes Agent 部署安装教程

## 核心知识点

1. **Hermes Agent** 是一款 AI 机器人，相比 Coze（扣子）更加节省 [[token]] 消耗，支持对接 [[微信]]、[[飞书]]、[[Telegram]] 等多个聊天平台。

2. **[[WSL2]]**（Windows Subsystem for Linux 2）是 Windows 系统下运行 Linux 环境的子系统，苹果电脑用户无需安装此组件。

3. **网络代理配置** 是部署 [[Hermes Agent]] 的关键前提，科学上网环境需要提前配置，否则可能导致聊天通道无法接收信息。

4. **代理端口设置** 主要涉及两个核心端口（7890/7891），第三个端口（7892）专门用于 [[Telegram]] 通道的对接配置。

5. **终端操作** 是安装过程中的核心技能，包括通过 `Win+X` 唤起终端管理员、输入 [[WSL2]] 登录命令等基础操作。

6. **一键安装命令** 是官方提供的自动化安装脚本，可直接复制到终端执行，无需手动配置其他参数。

7. **安装验证** 通过观察终端窗口是否显示编码写入进度条来判断安装状态，需要输入 [[WSL2]] 登录密码完成最终确认。

---

## 总结

部署 [[Hermes Agent]] 主要分为三个阶段：首先确认操作系统并安装 [[WSL2]]（Windows 用户必需），其次配置网络代理环境确保科学上网正常，最后通过官方一键安装命令完成部署。安装完成后需对接 [[飞书]]、[[Telegram]] 等聊天通道即可投入使用。遇到 443 端口报错时，切换网络节点通常可解决。
