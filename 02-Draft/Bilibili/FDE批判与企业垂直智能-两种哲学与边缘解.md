# FDE批判与企业垂直智能-两种哲学与边缘解

> **证据等级 E4**：本页提炼自一场播客访谈（时长 1 小时 43 分，转写 3.45 万字）。受访人张帆是元理智能创始人兼 CEO（此前任智谱 AI CEO 负责商业落地，更早为妙计旅行创始人、大搜车 CTO、飞书商业化负责人），**是 FDE 赛道的当事方**。文中观点为其本人主张，含强烈的自我论证成分与对同业（Palantir、OpenAI 等）的直接批评，**未经独立第三方验证**；引用时请保留人物归属。
>

## 一句话概要

张帆**不认同 FDE 这门生意**：商业上 FDE 只是"包装高级的外包"，能力沉淀在个人而非企业，注定随人流失、无法规模化；AI-native 上，正确做法不是让咨询式的人替企业建模，而是**让企业自己长出知识**——用一套"为学习建模"的环境，帮企业在自己的小场域里跑通**企业级 RSI**。落点是**垂直智能**。

## 两条根本问题（整场对话的骨架）

| # | 问题 | 张帆的立场 |
|:--|:--|:--|
| 1 | AI 商业化对企业而言，**以人和智能为中心，还是以企业为中心**？ | 以**企业**为中心。基模只是辅助，企业追求自己场域内的最优解 |
| 2 | **通用的泛化模型能力**与**企业真正需要的 AI 知识/能力**，本质差别在哪？ | 前者是公共分布（共识解，价值趋零）；企业的价值在**自己的边缘解** |

主持人（托老师）在开场即指出：张帆对 FDE 的概念与落地做了"非常系统、非常根本性的批判"，是这场两小时对话最有价值、最干货的部分。整场"一会儿激动、一会儿沉思、一会儿论辩"。

## 一、FDE 的两条批判

### 1.1 商业视角：FDE 是"高级外包"，能力沉淀错了地方

- **本质仍是定制与外包**，只是名字更酷。"FDE 本质上包了一个非常酷炫的名字，但往后看，本质上还是个（起底）定制——不就是定制跟外包吗？不新鲜，只是今天高级了一点：我是一个 AI 的外包，是不是就叫 FDE？"
- **"只要是定制的活，它就把能力沉淀在人，而不是沉淀在企业；沉淀在人，这件事就没办法规模化。"**
- 沉淀的对象具体是谁？**不是企业里的人，而是"背着大包小包，跑到一个国企住一个月"的那些人**（FDE 本人）。
- 后果链条：能力在人身上 → **人会离职、会跳槽、会扩散** → 行业壁垒趋同（"慢慢会让整个行业都有近似一样的壁垒"）→ 回到卷与碎片化。极端形态："如果每个人都觉得'我也能做 FDE'，那每人成立一个合伙企业自己干就好了——反正我一个人不用别人付工资，我到这儿包车包住住一个月，回来明天再打个包去，我房租都省了。"
- 这解释了为什么咨询/律所/公关这类智力服务业**最终都是合伙制**（"你管不了我，咱都是军阀"）——**FDE 最可能的形态就是军阀制**。
- **规模不经济**："管 20 个人跟管 2000 个人，中间的中层和管理损耗是极大的。"当业务增长抵消不了规模上升带来的效率下降，天花板就卡住了；此时"最直接的方法就是里面的人会离职出去单干"，因为恢复小公司后管理效率立刻变高——"所以大家又恢复到一个正常的（均衡）状态"。干过服务行业的人都懂（咨询公司、律所、会计师事务所、公关公司）。
- 因此"毛利变高"本身有隐含代价：**FDE 哪怕毛利变高，也意味着投入和产出要等比增高**。

### 1.2 用 Palantir 证明 FDE 成立，是**归因错误**

- 流行逻辑：Palantir 毛利率持续攀升 → FDE 模式好。张帆认为必须拆开：

| 论点 | 他的拆解 |
|:--|:--|
| Palantir 毛利高 | ①**它是 2012/2013 年成立的上一代企业信息化/数字化服务公司**（口述，见待验证点），属"上一代科技公司被 AI 重新激活"，与 Stripe、Cloudflare 同类；②毛利增长建立在**这次转型的前提之上**，而非"自身在 AI 时代的毛利增长" |
| 为什么变高 | **AI 让能力放大器变强**——"以前给客户提供服务要派一堆授权工程师，可能要花 100 块；今天一个人就可以解决，就花 10 块"。**这是 AI 带来的价值变革，不是组织自己带来的价值变革** |
| 不可复制的条件 | **最强的人**（大量 Founder level 的工程师）+ **最强的客户**（国防部/五角大楼这类超大型客户）。"用了最强的人和最强的中台，让这些人快速先适配了 AI，所以别人还是 100 块时，它已经率先做到了 10 块，毛利就上来了" |
| 正确的对照物 | **不应看 Palantir 的毛利增长，而应看 OpenAI、Anthropic 做这件事的毛利增长** |
| 可持续性 | 高毛利"**是暂时的，或者是一个特定环境的**"：客户过于独特——"又是锁价格，又是高收入解决复杂问题、抓拉登这种问题"；"**五角大楼不可能把 Palantir 的客户给到一个中型的做 FDE 的公司**，甚至给 OpenAI、给 Google 都不好说" |
| 可产品性 | 承认 Palantir"是上市公司，有自己的诉求和定义行业的要求"，但**从务实地看他们的东西，"没有看到特别明确能够被产品化的"** |

- 对 **OpenAI / Anthropic 做 FDE** 的评价："**我其实有点看不懂。唯一的解释是：大家都觉得对方的饭比较好吃——做 FDE 的想做 API，做 API 的想做 FDE。**" 讽刺点在于：**这两家都没去找咨询公司合作，都去找 PE 合作**——以为"我有企业、我有场景，我有 AI，咱俩一起搞，是不是就不要中间商赚差价了？" **其实中间商（落地方）有巨大的价值在里面，被低估了**；"所以现在也没声音了，至少好久没有听到这个方向的新进展。"
- 他也给过正面例子："（**埃森哲 Accenture**）我们合作过很多项目，**还是很靠谱的公司**——他们有很强的咨询能力、场景定义能力，以及很强的交付能力。这是原来合作的一些基础。"
- **竞争格局的一个观察（他转述 Dario Amodei 的采访）**："去年（Anthropic 的）Dario 接受采访时讲：在我们争夺一些企业级重要订单时，**我看到的竞争对手就是 OpenAI 和 Google，我没有看到任何一个中国公司**。" 他的即时反应是"这多新鲜——中国公司也没在你那儿消耗（预算）"。但**今年情况变了**：举的例子就是 Harvey（"底座用开放权重 K3，本地部署也得花几千万美金，但他花得起"）。
- 补充观察：**API 与 FDE 两条线的收入结构不同**——前者"几乎垄断性资源"、有网络效应；后者"哪怕毛利变高，投入产出也要等比增高"。

### 1.3 AI-native 视角：Ontology 是上一代逻辑，FDE 应该被 Agent 化

- Palantir 除 FDE 之外讲得最多的就是 **Ontology（本体）**，但"**Ontology 的本质是啥？是知识图谱**"——知识图谱是**上一代的逻辑**："因为原来的机器没有办法计算非结构化数据，所以只能把非结构化数据**降维**、损失掉信息，变成结构化的三元组，从而便于计算。但今天大家还在讲这个故事——**我感觉这事不够 AI native**。"
- 真正的 AI-native 问法：**"这件事如果真正 AI native，它为什么不是 FDE（而是）FDA？就是那个 Agent——我能不能把 FDE 这件事本身 Agent 化？"** 他认为"这可能是更加 AI native 的方式"。
- 为什么难？"**混淆了很多人与人之间的交流，和足够特化、异构的环境问题。**"
  - 完整链路极长：**建立信任**（"你要跟人家交流、让人信任你，帮人家按人家的思路解决问题，同时保持专业度"）→ **把问题转译成技术或 AI 可解决的问题** → **构造数据、炼模型、搭 Harness、训智能体**。"这是一个极长和极其复杂的链路，你想把它完全 Agent 化，在原有体系里是蛮难的、非常难的。"
- 为什么市场上仍在做？两类人：一类**没有深度思考**（"那 FDE 很好，我就来干这，肯定占了一部分人"）；另一类**有深度思考，但发现真难**。
- 他也点出现实："今天为止虽然大家都在用（AI），但很多人的底层思路还是**把 AI 当软件用**。"

### 1.4 现场人力的真实门槛

- 在智谱做商务时的实况："你要出去谈商务、跟（总）企业谈合作，你得带俩 researcher——我可以自己去，但要干活得找他们干。"
- 那两名 researcher 的重心是"**提高智能的上限**"，"就算便宜也便宜不到哪去，**一对起码 100 多万（年薪）**"。
- **"如果你没有这个级别的团队，你很难做得真的很落地。"**
- FDE 得是全才："**你得从研究开始——不是个科班、不是 985、没做过 research、没在核心的地方做过模型训练、没摸过百张卡以上，然后又没有在很多商业场景落过地，只凭一腔勇气，大学毕业生我就做 FDE，太不靠谱了。**"
- 类比律所："真正（能）开（起）律所的律师——①在某一领域非常专精（打伤法的、打刑事诉讼的）；②懂律所运营规则、懂怎么跟法院打交道、怎么规避风险。而现在 FDE 特别像**海淀（法院）门口那些盯着嫌疑人出来的家属、塞名片的那些人**。"
- 门槛判断："**FDE 确实今天把这个事想得太简单了，这是模型给人带来的幻觉**——他以为我能用 SKU Creator 造一个 SKU、简单聊两句话（总共没说 500 字），给模型最后生成了一个智能体，就觉得这个东西是我能教的。" 也点名了转型人群："我见过很多想做 FDE 的，这人都没玩过模型，说我做过互联网、做过软件，经常还做企业培训——不会是当年上门装（系统）的那波人，今天去做 FDE 了吧？"
- 但他明确："**我其实不觉得 FDE 没用**，我只是站在两个角度：①**站在生意的角度，FDE 未见得是一个好生意**（如果你不能找到一个年薪百万的工作，大概率干不了 FDE）；②就算是这样的人加入企业，"**他也未见得真正在企业的视角是合适的——因为企业的这种能力难道不应该自己持续拥有吗？到底以谁为核心呢？**"
- 他还补一句"真正做 FDE 的人是要很尖端的，但这个人如果只干 FDE 有点屈才了，本身应该在这个时代干更有意义的事"。

## 二、两种哲学：智能为中心 vs 企业为中心

| | 以**智能**为中心（基模公司立场） | 以**企业**为中心（张帆立场） |
|:--|:--|:--|
| 信仰 | AGI：只要我找到最大的智能，价格再贵你也会买 | 我只追求**这个范围内的最优解** |
| 价格 | "智能即王道，贵你别管" | 少一点智能、少一点成本，但**不降质**——靠**划定范围**实现 |
| 对企业的要求 | 跟随我、绑定我的 API | 基模都是我的辅助和助手，不把自己绑在基模上 |
| 典型手段 | 抢重要场景、锁大客户、锁 API | 独立构造自己的智能（**主权 AI**） |
| 环境变化 | 模型生命周期从一年/半年缩到一个月，你等不了 | 原来 SOTA 的模型三个月后默默无闻，所以不该绑死 |
| 类比 | 美国闭源大模型 | 中国开源模型 |

- **主权 AI**：这一概念"最早是**黄仁勋**提出来、针对国家的，现在被泛化到企业"。（对应例证：OpenAI 停止供货等事件，企业被迫自己干。）
- **本源追问**："**基模到底会不会吞噬一切？企业到底有没有价值？**"合起来是：**企业自身的核心能力会不会被基模的能力吞噬和改写**？以及**企业的 AI 化到底要不要依靠最强智能的那个基模**。"我觉得它依靠（最强基模）也没关系，但本质上这件事到底起的价值是啥？**很多企业，99% 的企业今天就没有想清楚，但是大干快上，觉得啥都能干。**"
- **收 API 逻辑正被"便宜到可以本地部署"削弱**：例证是垂类法律 Agent **Harvey** 的底座用的就是开放权重模型（K3）；"尽管开放权重，大到那个程度你本地部署也得花几千万美金，但**人还会花的**——他十来个亿（估值/融资），他花得起；他给 OpenAI 也不便宜，只会更贵"。基模方仍能收 license fee（"哪怕你是本地部署、是个成型的企业，license fee 收得也是不低的"），只是这笔账企业自己算得清。
- 关于基模方抢场景（如 **Kimi 发公告招生态伙伴做 FDE**，据受访人观察国内比美国更热，且可预见更多基模公司会跟上）的**悖论**："大家一头看到，从战略身位上讲，我要把一些重要场景跟大型企业锁住，这样才能保证它使用我的 API——特别是**当基础模型能力趋近的时候，谁能站住场景就变得更加重要**。但这里有一个**巨大的悖论，代表两种哲学**：**不绑定 Kimi，做这件事的意义就不大；如果绑定在 Kimi 上，那企业愿不愿意？**我觉得这里边有一个巨大的 GAP，可能是他们没看到的。"
- **反直觉观察**："通用智能越强，企业反而越用不起。"——"（某前沿模型）比最前沿的还卖得最贵，**为啥只占 11% 的收入？因为大家用不起，不是不想用**。"
  - 展开："一个用来做销售的模型，凭什么同时得是数学家、物理学家、诗人？（还得是）金牌物理特级教师、top sales——**你其实买了很多智能，浪费在你可能用不到的隐性空间里**。"
  - 场景化的用量感受："（前沿模型）一（稿）随便执行几个命令，**500 美金没了**，你就完全用不起。"
  - 他的替代表达："如果另一边是**极强的智能 + 极高的成本**，那这一边能不能是**少一点智能、少一点成本，但不让它低质**？办法就是——**泛化能不能有界限**？"
- **对尺寸竞赛的批判**："大模型的关键就是大"这话他早年公开讲过（当时大家乐），"一度说不是大，**最近大家又开始在比大了**——这跟中二男生比谁撒得远有什么区别呢？"
  - 他的解释：**做大是"确定性最强"的事**，但"从逻辑上讲，跟原来做软件一样——总是说要聚焦，后来你发现聚焦不好卖，那就再加个功能吧，功能不行再加，还不行，我免费吧。**大家在卷到极致的时候，常规手段搞不定就得上别的了。**"
  - 反向好评："**今天能坚持不比（不把模型做大），这是有很强的定力、非常有前瞻的**——这点智谱做得蛮好的，还是在强烈地控制（参数）尺寸。你做大肯定会好点，但没法用啊。"
- 一个中间问题（主持人引出、他确认）：**"企业（的模）存的到底是个啥玩意儿？企业到底要的是什么？"**——"绝大多数企业根本没有明白到底什么是我的竞争力"。

## 三、为什么"为知识建模"必然失败

### 3.1 为知识建模的四宗罪

传统 FDE 做法 = **为知识建模**（他称之为**"为知识切片"**）：访谈业务专家（"你销售到底啥逻辑？遇到这样的客户该怎么卖？客户一般会问哪些问题？"）→ 抽成脚本树/工作流/知识库 → 训练/反馈。

1. **信息已被二次压缩。**"你为什么要去访谈人？**他已经（被）压缩了**，是被加工后的、二次剩下的东西。"所以"问不同的人得到的信息不一样"；而"**人在 60（分）的认知上大家是一样的，60（分）以上各有各的绝招**"——高手方向不同，"你（接）在一块，那部分就抵消了，**共识就上 60 了，所以他的天花板很低**"。
2. **成本极高。**"你需要大量的人做标注、做训练、再反馈、再尝试。当然今天很多 FDE 都没有这么深，连训练都到不了，**只是写写 prompt、写写 skill，我觉得那太薄太薄了**。"
   - 报价参考："（深做一轮）**这项目没个 300 万你干不了**"；而老妖精本人的时间成本——"**我要是老妖精，我个人就是一小时我就要 5000 美元**"。
3. **它只是某一瞬间的切片。**"我们的业务每时每刻在变——环境在变、产品在变、价格在变、商业模式在变、竞争环境在变，这些都会导致经营策略变化，而经营策略是每天在变，**就像广告投放一样**。"而 FDE 的逻辑是"**了不起半年变一次，变一次这人就得过来搞一遍**"——"那倒是个长久的生意，**只不过企业受不了**"。
4. **旧知识难以叠加。**"你很难把旧的知识做叠加，所以整个是**乱成一团**。"

- **难度阶梯与斩杀线（他反复强调的口径）**："在企业应用这个领域，**做 60 分是极容易的事，70 比 60 难 10 倍，80 比 70 难 10 倍，90 比 80 难 10 倍——所以 60（分）比 90（分）差 1000 倍**。但你要知道里面**斩杀线在哪——可能是在 85：85 以下全是 0，85 以上一下变成 1**。所以我们原来做很多深度的 FDE，**不弄上两三个高手（一线学校做研究的那些人）混在里边，干个小半年，你不可能做到八九十分**。"
- **浅层玩法及其报价**："如果你只是常识性地给企业讲个故事——'我给你找几个智能体、做个（合同）审核、给你做个内部知识库、做个助手'——**这些东西都是两万、三万、四万的玩法**，今天都被大家翻出来了。（其实）真（正）接个飞书、（多维表之类的工具）就够了，那已经做得很好了。"

### 3.2 替代方案：为学习建模（为环路建模）

- 主张："**让我的能力，甚至我的 Agent，去接触你的知识、数据、信息和本体，让它自我学习成一套自己知道该怎么部署自己的东西。**" ——**人只定义环境，不参与操作**。
- **下棋样本的三代学习方法**（他的核心类比）：
  - **深蓝**（1997，赢卡斯帕罗夫）：**人观测、人总结、变规则**（专家系统 + 暴力计算）→ 适用范围极窄；
  - **AlphaGo**（2016）：**人观测、人记录、机器总结**（3000 万残局训练）→ 赢李世石；
  - **AlphaZero**（一年后）：**人只定义环境**（无任何先验，自己跟自己下三天）→ **100:0 完胜**，而算力**从约 1000 块 GPU 降到 4 块 TPU**。
  - 结论："**人很多东西是噪音。**"
- **为什么企业比通用模型更接近 RSI**：
  - 通用模型自己训自己会**坍缩**——"很多论文都论证过：自己造数据自己训，无论怎么筛怎么选都是一样的"；它**必须依赖外部信号**，而通用模型"要把全世界的知识都连上，你其实很难构造一个外界信号了"。
  - 企业**环境小、分支窄**，"完全可以在一个更小的分支的环境里快速跑通 RSI"。
- **星巴克/瑞幸的落点比喻**："我每次要选一个（址）造一个环境，开了店之后看用户待的时长、消费的状况——这不就是你的（闭环）吗？**不要人在总结了说'开店得有三个条件'，不用了——你这些原始语料直接给模型**，模型在这个里面再给反馈。如果能做到这一环，**企业里面原来每一次服务都是一次折旧，现在就变成每一次服务都是一次训练**——一个是贬值，一个是增值。" 这个独特分布又跟自己的环境形成**正反馈（"挣币环"）**；"那个正态分布变成了**在某一个环境内的（最终）分布**"。
- **钢琴老师 vs 钢琴演奏家**："它俩的分布不一样。原来（训练集）是所有老师、演奏家、学生平均的；现在咱们只要老师，我就得有个环境，不断（看）怎么教学生教得好。**我的目标到底是什么？是收课（费）还是学生教得成功、还是能拿奖？这都是我自己定义的环境。**"
- 与历史阶段的对照："这个路数反而回到了 **Deep Mind 当时让 AlphaGo 下棋的那个阶段——专业的模型和专业的 AI 干专业的事**。"差别在于："**以前如果没有基模，所有事都要从头干，代价太高**——我要训个老师，我得从造人开始干，太难了。**今天的逻辑是：我们从垂直回到了通用、再回归垂直，但这次垂直的生存方法不同**——说白了就是你用了基模的（基础）能力（能力变成了 API 的能力），而不是你整个模型里的数据和各种各样的能力；**借由基模加上我们对环境的理解，叠加一个虚拟世界，在这个虚拟世界里我可以无限采样，从而定义新的东西。**"
- **小提琴的比喻**（把"为学习建模"讲得最清楚）："我今天知道世界上有小提琴家，但**我不要让小提琴家来教孩子**——让小提琴家过来教我的老师，我的老师教完了之后，又通过跟学生训练，掌握了跟学生怎么交流，**他就变成了一个可以被无限复制的场景**。"（反例：家长要的是考级、结果，老师却讲"什么是小提琴、小提琴的历史渊源、音色"——"你的目的不是当艺术家，所以逻辑不（通）"。）
- 结论："**今天企业真正该建模的不是为知识，而是为学习，是为这个环路去建模。**"

### 3.3 合成数据：他自己立场的反转（重要一段）

- 他的自我修正："我尽量让自己保持空杯，因为我以前也是做 NLP 的，做 NLP 的人肯定会有（天然的排斥）……我 23 年、24 年的时候**极其不相信合成数据**，因为逻辑是：'如果我拿 100 条规则生成一万条数据去训练，理论上肯定过拟合了'——**这肯定是没戏的**。"
- **反转点**："后来我为什么想通了？**我为什么一定是规则比数据少呢？**如果我是一万个规则生成 100 条数据，它不就不 overfit 了吗？"
- 关键机制（他给的机理）："**在没有大模型的时候，这个逻辑（规则少于数据必过拟合）是成立的。有了大模型你会发现：大模型把人类的知识变成万亿级的参数，而我们的一个 prompt 或一个规则，其实它会均匀地散到这一万个参数上。**" 而且——"**你不制定规则，这些参数的分散和分布会导致一个错误的结果**"。
- 实证（他自己的项目）："我在给自己写一个（架空）历史型游戏，把 Pax Historia fork 了，再用 Codex 写（扩展）。我发现**你给它的人类史料只占这个游戏（内容）比例不到 10%**，剩下都是你剧情生成的、架空了创改历史的新合成史料——**那个事是驱动你整个游戏往前走的重要东西**。"
  - 其中的坑："现实史料和架空史料经常会**串**——现实史料串到架空那边。所以你要不断设置规则、鼓励合成数据进一步扩散、变更多条，**用它强行覆盖已经被合成数据改变的历史规则**。"
- 更一般的论断："**人本身就是合成**——'左脚踩右脚怎么能上天呢？'（结果）人就是左脚踩右脚上天的：爱因斯坦学了牛顿，自己研究出相对论，下一代的叠加——**它没有 overfitting**。本质上是因为它不是在（少数）规则的叠加，而是**无数规则的叠加，产生了新的化学反应，会互相（激发）——跟今天的多智能体一样**。"
- 他还提到这个赛道的舆论反复：24 年底所有人都在说"**人类数据不够、Scaling Law 失效**"（连 Ilya 都讲过"人类数据是化石燃料"），"后来你发现人类的数据（够）叮个屁，这两年大家全都用合成数据走了，后面就没人提这个话题了"。

### 3.4 预训练与私有模型的两波热潮（主持人引出，他展开）

- **第一波**（2023 年 BloombergGPT 出来时）："大家都觉得'一半金融数据 + 一半通用数据'很强，也都在笑话（它）。但很快 **GPT-4 出来，在 Benchmark 上完胜**，这一波就（熄）了。"
- **第二波**（现在）："Cursor 遇到（被上游模型卡脖子），所以要选自己的 Composer；Harvey 也是类似逻辑。"
- 中间的变量：**"RL 对于基座模型和对小一点的模型，现在它的（通用）性都越来越强，对 everything 都非常强。"**
- 他对这波人的评价与"预训练不可行"的论证：
  - "当时 Bloomberg（那波），我现在严重怀疑也是**一帮人一拍脑子就进来了，连模型怎么（训）都没搞**——没准也是一个 FD（E）团队进去给他们干的。这波人也不知道什么是 Pre-train、什么是（中）train、什么是 Post-train，**觉得 Pre-train 比较高级**，他能 Pre-train，我也能 Pre-train，一半数据我都得灌进去。"
  - "我们做过很多跟 Pre-train 相关的（项目）——**你帮客户做了 Pre-train 之后，他其实没有后训练，所有对话能力都是没有的**；而且**你不可能复制（模型公司的数据），没有模型公司会（给）你这套数据，凭什么？所以理论上 Pre-train 这条路就不通**。"
  - "而且今天模型训练的范围足够大、数据足够多，**没有什么（信息）在预训练上是没有的**。"

## 四、企业独特分布的三层载体 ★核心框架

### 4.1 三个承载层

企业真正要沉淀的不是知识，而是**自己的独特分布**。承载它有三种载体，**维度递增、可控性递减、价值递增**：

| 载体 | 维度 | 形态 | 特点 |
|:--|:--|:--|:--|
| **规则** | 几十~几百维 | Workflow | 最可控、人最好看见，**但表达力受限、无法泛化** |
| **文字** | 几千维 | Harness / Skill（提示词、知识库） | 表达力更强，**但开始有歧义**，可以争论 |
| **（脑）神经 / 权重** | 万亿维 | 模型本体的直觉 | 表达力极致、**别人拿不走** |

- **实例（客户记录）**："CRM 里把客户叫'成交客户'和'未成交客户'，这就是 Yes or No，两维很清楚、没有歧义，**但信息量很少**、便于传播、好控制。往上一层，你要写大量文字：'这个客户我们去拜访了、人很好、对我们很感兴趣、我觉得大概率会买……'——**信息量变大了，但产生了歧义**：有人看这个觉得能买，有人看觉得不能买，**这就开始有推理空间了**。到第三层（脑神经）：'我说不出来，但我感觉他肯定能买'——**这就是在他（的脑神经）里面，还没被压缩成语言、没被降维成文字表达出来的东西**。"
- **映射到 AI 形态**："（这三层）一个是 **Workflow**，一个是 **Harness**，一个是 **Weights**，就这三玩意儿。"
- 原话结构："**最笨的办法最可控的是沉淀在 workflow 上，高级一点的沉淀在 harness/skill 上面，再高级一点的沉淀在 weights 里面**"——"**越到上层价值越低，只有 weights 里才是别人动不了你的东西。**"
- 演进感："原来越来越像定程序，后面越来越像做人的教育、越来越像教人、越来越像写代码"——因此越往后越难，但**这是必然要发展到的一步**。
- **Workflow 的正确理解**："真正的 workflow 是在权重的逻辑里，**每次见到一个特殊场景生成一个一次性的 workflow——日抛**，这才是今天那些 artifacts 之类的东西。" 他也批评把公司变成"几千条 workflow"的做法（"你发现这玩意没法泛化"）。
- **最难的一环（老妖精）**："我们公司（有）老妖精——**老妖精的那些直觉和那些判断怎么沉淀下去？这事特别难。**" 只有 weights 能承载它，**"因为你只要把它写成规则，就（被）压缩了"**。
- 参照外部说法：红杉讲过 **"It's not your（weights）, it's not your（data）…"** 之类的表述（受访人转述，未给完整出处）。

### 4.2 "知识怎么来 / 知识怎么承载"

他指出企业叠独特分布其实只有两个问题：**①知识怎么来；②知识怎么承载**。"就这两问题解决了，这事就通了。"（承载 = 上面三层；来源 = 3.2 的"为学习建模"。）

## 五、边缘解即竞争力

- **正态分布的比喻**："基模把我们（的问题）加上（它自己的）影空间，投射到一个平面上，会出现一个**正态分布**：**中央是共识解，两边是边缘解**。由于训练基本上（以）Loss 最低（为目标），它肯定偏向中央（温度高一点可能稍有波动，但核心在中央）。**而中央解还有一个很形象的名字——很有道理的废话。这件事没价值。**"
- **价值在两侧**："**边缘解即非共识，非共识即竞争力。共识已经趋近于零了**——以前共识还有点体力价值可以卖，现在共识价格趋近于零。"
- **例子**："你把这套产品设计丢给模型问'好不好'，大概率回的都很平庸（'用户体验好、要快'）；但如果你问乔布斯，他可能说'it's a shit'，然后说'你这东西不够人文跟科技结合'；你再问马斯克，说'你这东西不够低成本十倍好、不够颠覆'。**这两个全都是边缘解——正因为有边缘解，才会有特斯拉、才会有苹果。**"
- **企业怎么拿到边缘解**："我要在模型的公共分布之上**施加独特分布、扭曲这个正态分布**——**让原来的边缘解变成今天的中央解，让过去的中央解变成今天的边缘解**。**我要去扭曲它，所以（现实）扭曲立场是企业的唯一解。**"
- **企业的价值定义（本场最凝练的一段）**："**今天企业的核心在于：你如何构造自己的那个场域，在那个场域内追求（SOTA），而我不追求一个公共场域的（SOTA）。我如何用一种能力，把公共场域的（SOTA）结合我自己的认知，抽象到我（自己的）垂直场域——把一个原来可能 100 万平方公里都有效的东西，变成两平方米有效，这就是我的价值；而且我只做这两平方米。**"
- **反"行业最佳实践"**："SaaS 时代给了我们一个特别大的误导，叫做**企业最佳实践**——企业有没有最佳实践？**如果你还靠着行业的最佳实践干活，你这企业还有没有存在的价值？**行业最佳实践是后一半人才看的，前一半人必须是个体最佳实践。"（例子：你不可能对一个作者说"你这文章不能这么写，我给你推荐一下别人的最佳实践"。）
- **反例（同题异解才成立）**：**瑞幸 vs 星巴克**是同一门生意里两个**相斥**的边缘解——星巴克要"第三空间"（人与人的连接、舒适场景），瑞幸要"买完赶快走"（足够高的密度、效率、便宜、马上送到家）。"你跟大模型说'我要开个咖啡店'，它大概率告诉你：咖啡得好喝、态度得好、速度得快、位置得好、空间温馨舒适——**多半亏**，**没有任何价值判断在里面，这就是公共解**。而瑞幸和星巴克各自有自己的边缘解空间，"只要在这个过程中不断循环前进，他就可以构造他自己的**企业 RSI**，有他自己的选店和评估模型，这些会源源不断进入他的模型——**而这个东西是基模永远没有的，因为你不可能这个人又像星巴克又像瑞幸，它俩是相斥的**"。
- **比喻：大海、灯塔与船**（他早年在活动上讲过）：
  - 基模是**大海**（汪洋、广阔、晃动），企业都想"看得更高、站得更稳"；
  - 第一种做法是**搭灯塔**："虽然你稳了、清晰了，但**海平面每年上涨 100 米（现在每个月涨 100 米）**，很快你这东西就白干了。"——**"你建灯塔建 500 米，现在你得建 1500 米，海平面还要往上走，过两年你还得再拆了再建。"** 对应实例：官方或框架一年一改的配置/文件格式（"你在 X 里要重新设定自己的系统提示、上下文文件和 skill"，"号称砍掉了 80%"）——**"这东西不叫资产"**。
  - 第二种做法是**造船**："你得造条船，**跟基模解耦**——他怎么长你怎么长，你在船上（掌舵）。但你就得分得很清楚，这个（耦合）界限是什么。" 这就回到"企业独特于基模之外的根本价值是什么"。
- **"用工具"不等于"是那种公司"**："很多企业觉得'我用了飞书、用了（知识库）、用了 ChatGPT，我就是 AI 公司了吗？'——**这就像移动互联网时代：我全公司都用了 iPhone、我所有的 App 都装了、我把（内部系统）也改成 App 了，我就是移动互联网公司吗？** 不一样——你自己（没）开发 App，你也不是移动互联网公司。"
  - 他甚至点回飞书的说法："**飞书管这叫'先进企业'**——（我）觉得飞书是非常好的（产品），**但我并不认为在企业的角度来讲，它会变成你最核心的竞争力**。"（"会议纪要记得快、周报写得清楚、合同审核清晰——肯定不是因为这个（而牛）。"）
- **"通用贵、垂直不贵"的推论**："如果你在通用领域追求足够聪明，那就是贵；但如果让它在**我的地盘里**足够聪明，这件事**就不一定贵**。你要找一个最聪明的人，那肯定贵；但我就要一个最聪明的编辑、教小提琴的老师——**找附近教得最好的老师就行，一个月顶天一万多块**。你把爱因斯坦请来教小提琴，**不值当**。"
  - 底层是**分工**："**人类社会的进化并没有让人变成一个 100 斤的大脑，而是让我们每个人开始进行分工。**"（PHD = philosophy = 爱智慧，古时先贤个个"无所不能"；工业革命三次都让分工越来越细；**"人工智能我真的不好说，我现在没有判断"**。）
  - 与世界模型同构："每个人独立训练之后，又从个体智能集合到群体智能……**整个社会不就是（MoE）吗？**"（亚里士多德那代先知式全才进化太慢、知识一多就只能 MoE 化；现在的新模型"两 T 参数每次只激活 80B"正是这个方向。）

## 六、蒸馏（"征留"）员工是伪命题

- **没有谁把巴菲特或乔布斯蒸馏了**。（"潮（汕）谷赚了钱"也没听说过谁把巴菲特征留了。）想蒸馏的其实是头部实验室最好的研究员——"**他的训练方法怎么蒸馏？我写个 skill 你都知道了？不可能的。**"
- 反例："我同时拿着 10 个 AI 一起来干活，我把我所有的文章都喂给了 Claude Code 和 Codex，我还写我的 writing skills——**他们照样是一个（六）字（辈）的（水平）**。**这明显是用模型用得还不够深。**"
- **模拟乔布斯失败的机理**："我把乔布斯所有的讲稿都拿来让（模型）模拟他，你发现**完全凌乱了**，逻辑上为啥呢？**因为他每次都要在以往的逻辑里去找语义相关的片段照着说，而且每次都是从头重新找一遍**——而我现在问的问题跟那个时代完全不一样，**你参考（旧）讲稿反而更不会讲了**。"
- 因此真正可行的中间层是**先提炼"逻辑与风格"**："你要先把他历史上所有的这些东西，**变成他的逻辑和他的理论风格**——比如'乔布斯极其追求科技与人文平衡、极其在乎极简主义'，你把这些做（成）描述，你发现会变好。**因为这个里面影响的不是原话本身，是它的思考逻辑。**"（"这个事我已经干了，我让（模型）总结我自己的风格（是可行的）。"）
- **论文佐证**（受访人引述，未给论文名）：
  - 角色扮演式前置提示（"你是一个产品经理、资深产品经理、二十年经验的产品经理……"）**效果最差**，输出"非常刻板和教条"；"而且一般越写越狠"；**"用过的人都知道差"**，"你没用过你不知道自己效果差"。
  - "你是小学三年级的老师"→ 说得**更像**小学老师，效果**变好**；**"你是数学家"→ 解题成功率反而下降**。
  - 解释："**他学的（是）那个人的语言风格，而不是那个人的思考逻辑**——思考逻辑是个影空间，他看不见，**越底层越思考不了**。而数学题得看思考逻辑，他还得假装数学家，还得再做题，注意力被稀释了，就更差了。"
- 比 prompt 更好的沉淀方式：**训到权重上**——"因为它的泛化就散在万亿参数上，而不（只）是表面那几个（词）"；"你放在 prompt 里 few-shot 已经不少了，**但那个训练你可以 500-shot**"。
- FDE 的现实成本对照：靠访谈老妖精 + 反复标注 + 训练 + 修正 + 再造数据训十轮——"**没个 300 万干不了**……**好点，但不本质**。"（主持人追问："这就乔布斯给你十篇发言稿，他就真的是乔布斯吗？"）

## 六·五、他对当下工具的直接评价

- **Harness 的本质**："（Harness 不是具体 Agent，而）**是一套你能够把 Agent 搭起来（的框架）**。DeepSeek 的 Harness 是什么？**好玩——你玩它就跟玩 Minecraft 一样，你不断地插拔、搭。**"
- 但他自己的取舍："我今天竟然觉得 **Claude Code 还是非常好用的**，**Codex 也蛮好用的**。但你说用 DeepSeek Harness——**我觉得可以玩玩，但它不是我的主力应用**。"
- 一个反共识判断："（DeepSeek 这类）**只能本地部署，这也是反共识**。"（他澄清自己"不是因为它是（本地部署）才宽容，就是因为它（好玩）"。）
- 他对"好玩"与"好用"的区分："**好玩、好用是两件事**。今天 AI 很多情况下是好玩，但你能把好玩用出价值其实很少——**你要把它真正变成一个可用的东西是很难的**。"

## 七、落点：垂直智能公司与数字员工

- **自我定位**：既不说自己是 FDE 公司，也不追 RSI 这个词（"有点追风"）——**"我更希望讲：我们其实是一家垂直智能的公司——我们是把通用智能转化为企业的垂直智能，并且把这个过程作为产品化。"** 他预判会有"垂直智能不就是（垂域）模型吗"的质疑，并承认**"反共识（解释成本高），但这也屏蔽掉了红海"**。
- 时间线（他认为自己最早在讲）：**"我们去年（一年前）讲的故事就是商业强化学习**——把（强化学习）的逻辑如何搬进商业环境，为每一个企业家构造自己的商业数字员工"；当时不叫 RSI。他对 RSI 这个词的评价："**（它）也是一个庸俗的词，但本质上是企业自己要去做的事——企业自己的自我进化。**"
- **落地载体 = 数字员工**，但他刻意区别："**数字员工不是工具，而是能独立完成、跟人做对标、完成结果的东西。**"（他承认这个词已经被叫烂；也澄清不是 RPA、不是（浏览器）助手那类"工具"。）
- **可拆分的边界（三种活）**：
  1. **数字化层面** → AI 都能解决；
  2. **物理层面** → 还需要人；
  3. **弱逻辑、情感与信任** → 要人来解决。
  **"本质不是让 AI 替代人，而是让 AI 来放大人。"**
- **为什么"替代劳动力"是最务实的切入点**："（为企业 AI 化）你总说（落地），根本说不清什么叫（落地），但**我抽象成一个最简单最务实的逻辑：企业本质上是创造价值的，而所有价值创造来源于所有劳动力——所以最简单的逻辑就是 AI 能不能直接替代劳动力**"，且替代的不是"走流程"的那种（"他里面带着泛化，客户问啥都有可能，你都得接得住"）。
- **为什么不能用脚本/知识库顶（红线例子）**："客户问啥都有可能，但里面还有很多红线——**比如体检，我总得先问你是谁吧？你不说你是（身份），我是不可能说你报告情况的，说了我就违规了。**这东西**不是一个脚本（能解决），也不是一个知识库做对标**，而在于**我能不能基于企业的软性文化训到模型、训到 Harness，做一个综合的端到端体验，让他感觉就真的是企业的员工**。"
- 已落地的场景举例（他提到的客户用例）：**旅游规划专家**（"不要寄（机票）"等）、**客户沟通与跟进的线上流程**、以及"帮着做业务专家"。他的观察："很多企业里，**当人力成本足够低，其实很多原来不通的商业模式可能都通了**。" 价值路径是："**帮助企业把闭环跑通、快速扩张形成闭环，不断把核心能力收回来**"——"这件事今天已经初步跑通。"
- **反标准化**："**不是把它（过程）标准化，而是符合每一个人的需要——是反标准化，坚决要反标准化。**"标准化是工业时代的产物（详见 §八）。
- 他明确标注**推演与现实的差距**：这套东西"**逻辑上理论成立就一定会发生，所以我（推演了脚步），但今天都没做到**"。

## 八、组织与时代的判断（延伸推演）

### 8.1 人、软件与组织

- **固态组织的构成**："原来企业里所有的组织全部都是**固态的**——里面有 **SOP、有（各种系统）、有人员的固定分工**（"这维系了太多人的利益，那是另外的问题"）。"
- **一个类比的比喻（部门与协同）**："（未来的组织）很像 **NVLink 的显卡**——每一张显卡（自己）在算东西，但如果你中间要拉根线、要把算力连起来，（普通连接）连不通，**只有 NVLink 连上才能保证中间（那条）腿（不）掉**。"（与之对照：模型的训练越来越独立化——每个专家自己训自己；而人的需要可能越来越通用化——"大家都应该去读 MBA，MBA 没给大家长别的本事，就长了一个'你应该怎么认识商业实践'的本事"。）
- **人 = 模型，软件 = Harness**："人是一个概率性动物，虽然人是有幻觉的，**为什么要增加软件呢？是因为（用）逻辑来限制它的坏幻觉**——所以**软件其实就是人的 Harness**。"
- **适配方向反转**："**原来的逻辑是：由于软件有成本，所以是人（来）适配软件；而今天的逻辑是：软件没成本，所以是软件在适配人。**"
- 推论："未来的（形态）最后可能**回归到数据库**"——"只要数据的结构是一样的，咱俩就能交流。你面前是一个 CRM 界面，我面前是一个 CLI，没问题。"**界面液体化，软件趋向日抛**（"现在很多人都在 artifacts 里边，弄完就丢了、一次性的"）。
- **液体化 / 颗粒度革命**："今天一切东西全部都液体化——界面液体化、组织液体化、业务液体化，因为**脑力足够发达，这些东西可以无限生产**。"他称之为**颗粒度革命**。

### 8.2 两种组织哲学：腐化逻辑 vs 生长逻辑

- **软件/固态组织 = 腐化逻辑**："一个 SaaS 软件，什么时候是它最好的状态？**是它在开发完的那一刻**——因为从此之后它就开始了熵增、开始了特例、开始例外，慢慢变得不适应环境。"
- **模型/液态组织 = 生长逻辑**："而模型什么时候生成是最好的？**不是，是最坏的——它还没有开始学习**，从那一刻起就开始不断跟外界学习。"
- 结论："组织从一个健康的组织变成一个腐化的组织，**这个过程每一个人都经历，它是必然的，跟你牛不牛没有用**。"（他也承认"后者这（件事），这个世界绝大部分人还没（意识到）……**但理论上成立就一定会发生**"。）

### 8.3 为什么还会有企业（科斯式追问）

- "为什么会有企业，为什么不是市场？**市场是一个无形的手，而企业存在的逻辑是：你在某一个范围内能够做到有形的手的效率高于无形的手**，而且你必须让这些人联合在一起。"
- 推论："**当大家的训练目标一致、多人收集的数据叫共同训练的时候，企业依然存在**——只不过每个人能效会变得极高、会两端极端化。"
- 与 FDE 呼应的追问：**"如果我一个企业里边有一千个人，每个人都是一个综合个体的话，那他们为什么不能变成一千个 FDE 呢？"**
- 对"公司会不会变小"的回答："未来的公司不见得会变小，**人的产能会变高倒是真的**。会不会产生 10 万亿美金（级）的超级公司？我认为有可能，但人数依然（可观），**因为每个人只被放大了而已**。"

### 8.4 管理学要被重启 / 认知与教育的重置

- "AI 从一个模型开始，进入到一些商科的逻辑里面——**我觉得管理学是要被重启的**。"
- "**企业家教育要被重新定义**：原来的逻辑是大家都来学知识，**今天知识已经变得过于廉价**——大家要学的不是知识，而是**如何把这些知识（训）到企业内部的权重上**。而这（件）事的方法，可能跟以往都不一样。企业的形态、组织该怎么管理，也不一样了。"
- 点名的旧范式："**（稻盛和夫的）经验、IBM 的成功经验、松下幸之助的成功经验、郭台铭的成功经验，今天还有没有用？我觉得长远看肯定会越来越弱。**"
- **判断：人工智能不是第四次工业革命**，而是与工业革命平行、甚至**反工业革命**的事情。
  - 论证：工业时代的前提是"**体力无限扩张（有电就有无限体力），但脑力不足（还是 8 小时）→ 所以体力要为脑力妥协 → 办法就是标准化**"：生产端=分工（每人只干一件事），消费端=标准产品（"最典型是福特 T 型车，只有黑色"）；职业清单越来越长、越来越标准化（"把乡村手工业者的地圈走，变成工厂，一天干 16 个小时"）。
  - 今天："**AI 带来的变革是脑力与体力重归对称，都可以无限扩张**"（"如果具身智能不发展，甚至可能带来体力的（短缺）"）——**结果就是反标准化与颗粒度革命**。
- 收尾判断："你要**从 AI 的第一性来判断你产业未来变革的格局，提前做布局，极早地找到自己的避风港**，让自己形成一个螺旋上升的企业内部的企业 RSI。"
- 金句："**你今天在一个（AI）这种底层变革的时代，要知道这是个地壳变动——你还天天跟那挖护城河，挖得很深，扭头一看，城没了，只剩护城河了，这有啥用呢？**"
- **元理智能的一句话版本**："**如果我们认为 AI 的知识来源于无数的探针跟物理世界的连接，而这个探针最好的载体就是企业——所以我们用另外一种方法来帮助企业来构建探针。**"（主持人补充：这与"给企业一套工具和框架，让它自己建构自己的（AI）"殊途同归。）

## 九、历次热点年表与 Token 叙事（他的一轮行业复盘）

他把 2023 年以来的企业 AI 热点串成一条线，问了一句："**站在今天往回看，这些东西堆起来真有用吗？有什么价值呢？**"

| 阶段 | 当时的流行说法 |
|:--|:--|
| 23 年 | "**Prompt Engineer 是未来最重要的职业**，未来只剩这一个职业"（"我一听这词我也信了"） |
| 之后 | 搭 **workflow**；搭**知识库**；**向量数据库**（"我一直没搞懂这跟向量数据库有啥关系——向量数据库里（做）的都是老公司、上个时代的数据公司，现在都告诉自己（叫）向量数据库"） |
| 再后 | **GPTs**（"以后再也没有 API 了"）；**一体机**（"买到了之后再想干啥用，那是固定资产，对财务特别好"） |
| 再后 | "**（某产品）才是未来**，每个人都要学智能体"；**MCP 和 Harness**；**"养虾养马"**（各类智能体/工具的大战，"养了点马（居）就停了"） |
| 当下 | 大家又开始**比模型大**（见 §二） |

- **Token 叙事的批评**："大家一开始说所有人都要用这个，**比谁用的 Token 量大**——号称这个人（牛）一天用 100 亿、200 亿 Token。**我太知道该怎么消耗 Token 了，消耗 Token 不出（活的）密集太多了**：你会给它大量信息（混）的图像为主的文档，一下就消耗完了；或者你说'请你设置一个（目标）解决 NP 问题'，你就等着去吧，可能算 10 年。**当时很多大厂在搞（Token），我说你这大厂边没人劝老板吗？你们不知道这事不对吗？**"
- **企业家的两类**："**面对一堆没有想明白的传统企业家，和以为自己（想）明白了（其实）不明白的上一代互联网企业家和 IT 企业家**——在他们不明白的情况下，他们的钱更好赚。**所以你要想清楚：想赚短期的钱还是长期的钱？** 我觉得后边的钱更大，前（面）的钱更小——今天可以赚几个，但那件事（追求智能上限的人）都不想干，我也不想干。**但当你的通用智能不够好的时候，你只能这么干。**"
- 他的总结："**AI 给（人）带来了很多幻觉**——人本来幻觉就（很）严重，（现在）它是一个在（借用）智能（的）人，把它当成自己拥有的智能（了）。"

## 九·五、他自称"瞎聊/科幻"的两段推演（他也明确标注了不确定性）

- **技术上：未来的 MoE 会允许每个专家独立训练**——"而且它就有可能变成**一边训一边推**（训推一体），让自己的（记忆）真正进入（参数）"，从而**改变过去"先预训再后训"的方式**："过去的训推一体（是）一期一题；未来可能就是这种小范围的、基于每个 MoE 的训练（范式）。" 他补充方法论上的一层："从**第一性**来讲，你都是从物理世界收集信息——**分开去收集和你整体收集，可能都有利弊。**能不能到那一步，我不知道，我纯粹是像科幻一样。"
- **类比人类社会**："未来如果人类作为一种方式——**每个人从出生独立学习，继承别人的预训练，学完之后再变成集体，集体产生的数据沉淀下来，再学习**。（就像）有脑机接口之后，我们不就是可以独立预训练了吗？每人就可以自己预训练。"
- **对国产模型的判断**："国内比较重成本（的）DeepSeek 跟智谱都还算，**它们这个东西还是用得起的**。（某大模型）那边搞太大了——效果是挺好，**太费了，训一会儿（额度）就用（没）了，我都用不太起来**。它那个最大的问题，而且**推理速度慢**——他 Size 大、没（量化）折（扣），很耗卡，大概只有 B300 才能跑，所以很（难）不缺卡。但他这个东西**会拖累他训练**：到底给不给推？你不训练（又不行），左右为难。所以这个（路）子**也对也不对**。"
- **他对"征留（蒸馏）员工"这个市场热点的判词**："（今天市场）很多信息是非常错误、但是被大规模传播的。比如（蒸馏）员工——**靠谱吗？** 我们这种公司就十个人。最大的问题是：**有多少员工值得你（蒸馏）啊？**……我宁可（蒸馏）大师。**没有谁把巴菲特征留了，也没有谁把乔布斯（蒸馏了）做了一个好产品**；现在 OpenAI、Anthropic、Grok、Kimi、智谱这些厂最好的研究员，**你都蒸馏不了**。"

## 十、对我们的启示（我们的解读，非受访人原话）

1. **这条批判正好补上我们 FDE 素材体系的反方**：库里已有的 FDE 素材（实战营、能力模型、白皮书）偏"怎么做"；本篇问的是"**这生意成不成立、能不能被 Agent 化**"。两边并列，可直接用于客户端的"该不该做 FDE / 该不该自建"决策场景。
2. **"三层载体"可迁移成落地交付的分层设计**：给客户交付时明确区分——workflow 层（可控、易维护、易被抄）、harness/skill 层（表达力、有歧义）、weights 层（真壁垒）。这给"我们到底交付了什么资产"一个能对客户讲清的结构。
3. **"边缘解"是可复用的对客话术**：客户问"大模型都能做，你凭什么收费"——共识解趋零、价值在于扭曲分布，是业务方能听懂的价值主张。
4. **"85 分斩杀线"是可用的判断工具**：浅层交付（智能体、知识库、合同审核，报价量级两万到四万）在 85 分以下"全是 0"——提示我们把报价与价值叙事绑在"过不过斩杀线"上，而不是功能清单长度。
5. **"大海/灯塔/造船"可用于说服客户自建**：官方框架一年一改（建灯塔会被上涨的海平面淹没），而"船"是与基模解耦的自我进化能力——这是"为什么不能只买现成工具"的好比喻。
6. **风险提示**：本页观点带有强烈的立场驱动（受访人是当事方，且正在做与 FDE 竞争的产品），其中"Palantir 毛利不可持续""FDE 不是好生意"等结论**未经数据交叉验证**；对客引用前需补独立证据。§九 的年表与 Token 叙事属受访人主观复盘，宜作为线索而非结论。
