# 15分钟，搭建你的 AI 职场秘书团 — 结构化笔记

## 一句话核心观点

面对让人眼花缭乱的 AI 工具，正确的做法不是寻找"最强的那一个"，而是识别每个工具的**专属超能力（superpower）**——即它"比其他工具做得更好的那件事"——再按任务需求把工具组合成一个各司其职的"秘书团"。

> 视频作者把三年试错经验压缩成唯一一条结论：只用回答"每个工具在什么上比别的工具更强"。范围上，本集讲**生产力 AI 与创意 AI**（上一集讲日常型与专家型 AI）。

## 核心框架：按"超能力"选工具，而非按"综合强弱"排名

通用动作：先判断任务需要哪种能力，再选对应工具。可用两个维度给创意类工具定位——**用户对输出的控制程度**与**多产物之间的一致性**。

### 一、生产力 AI（Productivity）

按"AI 与你的工作系统之间是什么关系"分三类：

| 类型 | 超能力 | 适合的任务 |
| --- | --- | --- |
| 原生集成型 | [[native-integration]] | 跨多个数据源一次性检索与综合 |
| 智能代理型 | [[agentic-workflow]] | 在系统内创建、填充、重组内容，而不只是回答问题 |
| 语音输入型 | [[voice-prompting]] | 降低表达摩擦，让 AI 获得更丰富的上下文 |

**1. 原生集成型（Native integration）**
- 关键判断：这个 AI 是否"本来就长在工作系统里"，还是从外部"接入"。
- 第三方连接（third party connection）从外部连入，因此**更不稳定，且访问不到某些文件类型**（如 Google Sheets）；原生集成则让各应用通过它无缝互通。
- 核心洞察：**超能力不在模型本身，而在原生集成**——它能在一次查询里跨邮件、文档、日历完成搜索与综合。
- 可迁移问题：*"我的数据分散在几处？是否需要一次查询同时拉取多处？"* 若是，优先选原生集成方案。

**2. 智能代理型（Agentic）**
- 与"只会回答"的区别：它会在工作系统里**实际动手**。可抽象出一个三级能力标尺，用于评估任何代理型工具：
  - **Level 1 基础**：在空白页里起草内容（多数对话式 AI 都能做到）。
  - **Level 2 行动**：依据现有模板/结构，自动新建条目、继承格式与语气，并写入属性字段。
  - **Level 3 关系操作**：理解并重排对象之间的关系（relations），跨页面合并、迁移关联内容。
- 可迁移问题：*"我要的是它帮我'搜索'，还是让它在系统里'动手'？"*
- 注意：购买代理型工具 ≠ 买到它背后模型的满血版；这类工具常用多个模型的 fine-tuned 版本并针对自身工作系统优化，日常单独使用并不如原模型强大。

**3. 语音输入型（Voice-to-text）**
- 核心价值不在转写本身，而在于**去掉打字摩擦后，人愿意提供更多上下文**。
- 数据：打字写一段 prompt 约需 **5–10 分钟**，往往写两段就停；改成语音"脑暴"**约 30 秒**即可补全原本会省略的细节——涉及的团队、时间线、想要的语气。
- 可迁移问题：*"这个任务的质量是否高度依赖我给了多少上下文？"* 若是，改用语音。
- 已知局限：移动端（iPhone）体验差，每次激活需在应用间来回滑动；且判断其长期护城河存疑——平台方只要把原生语音模式做到同等智能自动编辑水平，就可能抹平差距。

### 二、创意 AI（Creative）

按"控制精度"与"序列一致性"分四类：

| 类型 | 超能力 | 适合的任务 |
| --- | --- | --- |
| 完全控制型 | Precision / manual mode | 追求最大控制精度、愿意学语法 |
| 自然语言精修型 | [[prompt-engineering]]（自然语言迭代） | 用大白话局部修改，不必重来 |
| 序列一致性型 | Memory / consistency | 多张相关图之间保持角色与元素统一 |
| 生成+动画一体型 | Generate & animate | 从静图到动图，不离开同一工具 |

**1. 完全控制型（Manual mode）**
- 类比：多数图像工具像手机的"自动模式"（对准就拍，99% 的人满意）；这类工具像"手动模式"，可调光圈、曝光、风格等参数。
- 代价是学习曲线：多数人看不懂其语法，正如多数人不懂"光圈"。
- 例：同一句自然语言描述，加上语法参数后输出差异巨大——`16:9` 设定宽高比、`Ref1` 锁定参考图的视觉风格、`No` 排除特定元素。
- 现实用法：即便付费，也常被当作**研究与灵感**来源——逛社区画廊找喜欢的效果，再用更简单的工具复现。
- 可迁移问题：*"我是要'聊天出图'，还是要'精确控制'？愿意为控制力付学习成本吗？"*

**2. 自然语言精修型（Iterative editing）**
- 超能力：用 `plain English` 做精确编辑，具备准确文字渲染与"不必从头再来"的迭代能力。
- 例：先生成一张信息图，再连续追加指令（去掉底部方块 → 应用某美学与品牌色 → 优化为 1:1 方形），直接产出可发布成品；或把现有照片改成"高科技智能镜片"，而照片其余部分保持不变。
- Pro tip：需要 4K 高分辨率输出时，用 Google AI Studio 并绑定信用卡按 API 计费。
- 补充：该模型是 Google 四个图像模型之一，各有所长；此模型最擅长用大白话做**精确编辑**（改文字、改颜色）。
- 可迁移问题：*"我需要在已有产物上做局部微调，而不是从头生成吗？"*

**3. 序列一致性型（Memory / consistency）**
- 超能力：在**一组相关图片**之间保持角色与视觉元素一致。注意——**单图精修强 ≠ 多图一致强**，这是两种不同能力。
- 例：同一 prompt 让两个模型生成动漫角色。前几张都保持一致；当第三张要求换到完全不同的场景时，一个模型开始丢失一致性（难以分辨女性角色），到第五张彻底崩坏（把上一张的元素混入，画面变得无意义）；另一个模型则能保持发型细节与画风。
- 现实含义：制作培训材料、需要吉祥物出现在多个场景时，一致性能力决定成败。
- 可迁移问题：*"我需要的是一张完美，还是一整组连贯？"*

**4. 生成+动画一体型（Generate & animate）**
- 超能力：在同一应用内生成图像，并让图像之间"动起来"。
- 工作流（frames-to-video）：生成两张状态图（如线框草图 → 成品渲染图）→ 用关键帧转视频 → 加简单 prompt（如 `smooth transformation, static camera`）→ 工具自动补全中间运动。
- 另一种用法：不必从零生成两图，可直接拿一张现有照片，用图像模型加效果得到"前后对比图"，再动画化。
- 可迁移问题：*"我是否希望'生成'与'动画'在同一个流程里完成，而不是在多个工具间导来导去？"*

## 关键细节与可复用做法

- **选工具先问"超能力"，而非"排名"**：并列比较只有落到具体任务上才有意义。
- **原生集成 > 第三方连接**：凡是从外部接入的方案都更脆弱、能力更受限；当任务需要跨多个数据源时尤其优先原生集成。
- **警惕"大厂顺手加功能"**：第三方工具的护城河，可能因平台方把该功能做成原生而在一夜之间消失。评估工具时要考虑这一点。
- **沉淀与工具无关的"系统"，而非工具教程**：花 5–6 小时搭建的应是"用 AI 的系统"，能沿用多年，而不是撑到下一次工具更新就失效。
- **语音是低成本的上下文增强器**：上下文越丰富，输出越好，而语音把补充上下文的门槛降到最低。
- **案例数据（原生集成型生产力场景）**：一个营销项目收尾时会有 **50+ 会议转写**（各自埋在独立日历邀请里）、**数百页共享文档笔记**、跨团队 **200+ 邮件线程**；过去人工梳理需 **1–2 周**，现在一次查询即可跨邮件/云盘/日历综合，定位相关文档、拆解活动目的与结果、并起草汇报文档。

## 对读者的可迁移启示

1. **把工具箱当"团队"来配**：用"任务需求 → 超能力"的映射做分工，而不是找单一万能工具。
2. **用三级标尺评测"代理能力"**：只会起草（L1）→ 会按模板创建并写入字段（L2）→ 会理解并重排对象间关系（L3）。
3. **区分"控制力"与"易用性"两种产品定位**：控制型适合愿意学语法的少数人；自然语言型对大多数人够用。先想清自己属于哪一类。
4. **把"一致性"当成独立维度**：单次输出好不等于系列输出稳；需要成套内容时，专门评估模型的一致性。
5. **优先选择减少工具间切换的流程**：生成与动画、编辑与迭代，能在同一环内完成就少一次损耗。
6. **沉淀与工具无关的系统**：工具会变，可迁移的工作流与框架才是长期资产。
7. **把平台方动向纳入判断**：任何依赖"平台尚未原生支持"的第三方工具，都要评估这一前提能维持多久。
